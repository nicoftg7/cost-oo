📥 Cómo importarlo en Odoo

  1. En Odoo, entrá a Productos en vista de lista.
  2. Abrí el menú del engranaje ⚙ al lado del título “Productos” (en versiones anteriores, el menú Favoritos) y elegí Importar registros.
  3. Subí el archivo {{ archivos.import }}.
  4. Revisá que cada columna esté reconocida así:
    • id → ID externo (es la que hace que se actualice y no se dupliquen productos)
    • default_code → Referencia interna
    • name → Nombre
    • standard_price → Costo
  5. Tocá Probar. Si no aparece ningún error, tocá Importar.
